# 台股總經指標測試（投資策略研究 第四、五輪）

目標：找出能在無後見之明、統計顯著下預測台股（加權指數／0050）的總經指標。

| 檔案 | 內容 |
|---|---|
| `00_預先登記.md` | 第四輪：21 個總經指標、5 等級景氣分數的事前規則 |
| `01`~`04` | 第四輪程式（建分數、檢定、四階段探索、單一指標） |
| `05_結論.md` | 第四輪結論 |
| `10_預先登記_官方燈號即時資料.md` | 第五輪：國發會官方景氣燈號／領先指標「當時公布值」事前規則 |
| `06`,`06b`,`07` | 從鉅亨網新聞抓取並解析當時公布值 |
| `08_test_official.py` | 第五輪檢定 |
| `11_結論_官方燈號.md` | 第五輪結論 |
| `raw/` | 原始資料（國發會開放資料、FRED、Yahoo、新聞） |
| `out/` | 結果輸出 |

執行：`pip install pandas numpy scipy`，然後依序 `python 01_build_score.py raw` → `02` → `03` → `04`；第五輪 `06` → `06b` → `07` → `08`。
